# PhoneGyro Hardware Protocol

*[Read in English](README.md)*

Открытый контракт данных для контроллеров движения. Любой микроконтроллер и
любая комбинация гироскоп/акселерометр совместимы с хост-приложением
[PhoneGyro](https://github.com/MrHoustonOff/iphone-gyro-controller) — без
кода под конкретного производителя — если устройство реализует уровни,
описанные в [`docs/PROTOCOL.ru.md`](docs/PROTOCOL.ru.md).

Это тот же принцип, что PhoneGyro уже использует для телефонов: любое
устройство, умеющее отдавать данные по стандартному браузерному API
`devicemotion`, просто работает — неважно, iPhone это, флагман на Android
или бюджетный планшет. Этот репозиторий переносит тот же принцип на
физическое железо.

> Заметка: проект (хост-приложение + этот протокол) переименован с
> "GyroBridge" на "PhoneGyro" в хост-приложении v2.0.0. Переименование
> завершено; релизы хост-приложения GyroBridge v1.x устарели. Сам протокол
> не изменился.

## Содержание

- [`docs/PROTOCOL.md`](docs/PROTOCOL.md) — полная спецификация (английский).
- [`docs/PROTOCOL.ru.md`](docs/PROTOCOL.ru.md) — полная спецификация (русский).
- `firmware/` — референсная реализация для Arduino Nano + GY-521 (MPU-6050).
  Появится следующим шагом; это рабочий пример, а не единственное
  поддерживаемое железо.

## Статус

Черновик v1.0. Разрабатывается параллельно с хост-приложением. Формат кадра
и семантика достаточно стабильны, чтобы на них ориентироваться, но ещё не
заморожены окончательно — смотрите теги/релизы этого репозитория после того,
как первая референсная прошивка будет проверена на реальном железе.
