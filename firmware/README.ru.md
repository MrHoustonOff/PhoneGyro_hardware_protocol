# Референсная прошивка

*[Read in English](README.md)*

Референсная реализация [PhoneGyro Hardware Protocol](../docs/PROTOCOL.ru.md)
для Arduino Nano (ATmega328) + GY-521 (MPU-6050), адрес I2C `0x68`.

## `reference_nano_gy521/`

Один файл-скетч, без зависимости от сторонней библиотеки MPU-6050 (только
Wire) — чтобы его можно было прочитать целиком как настоящую референсную
реализацию протокола, а не гадать, что делает библиотека внутри.

- Будит MPU-6050, настраивает ±2000 °/s / ±2 g / внутреннюю частоту 200 Гц
  (`SMPLRT_DIV` = 4 при включённом DLPF). Диапазон гироскопа намеренно
  широкий, а не самый чувствительный из доступных: ±250 °/s клиппируется на
  обычном быстром взмахе или вращении, незаметно занижая реальную скорость
  поворота и уводя интегрированную ориентацию всё дальше с каждым быстрым
  движением (проверено вживую). ±2000 °/s — ровно то, что используют
  настоящие DS4/DualSense контроллеры именно по этой причине; более грубое
  разрешение, которым за это платится, на практике незаметно.
- Отправляет кадр метаданных (`TYPE=0x00`) при старте с этими
  параметрами, затем опциональный кадр имени устройства (`TYPE=0x02`),
  затем шлёт кадры данных (`TYPE=0x01`) на 200 Гц и раз в секунду повторяет
  кадры метаданных и имени (протокол v1.1), чтобы хост, открывший порт без
  перезагрузки платы, всё равно узнал диапазон.
- Каждый кадр проверяется CRC-8/SMBUS и пишется одним вызовом
  `Serial.write`, согласно Уровню 5 протокола.
- `BUTTONS` всегда `0`, и битовая маска возможностей в метаданных честно
  говорит, что кнопки сброса на этой сборке нет — её действительно нет.

### Схема подключения (из `DEVICE_SPEC.md` в репозитории хоста)

| GY-521 | → | Nano |
|---|---|---|
| VCC | → | 5V |
| GND | → | GND |
| SCL | → | A5 |
| SDA | → | A4 |
| AD0 | → | GND |

### Прошивка платы

Открыть `reference_nano_gy521.ino` в Arduino IDE, выбрать "Arduino Nano"
(если прошивка не идёт на клоне — попробовать старый бутлоадер), выбрать
COM-порт CH340/FT232, залить. Дополнительные библиотеки не нужны.
